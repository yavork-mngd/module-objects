# Objects Module

![Module Version](https://img.shields.io/badge/version-0.1.0-orange.svg)

The **Objects Module** is the core industrial planning component of the yamon.eu ecosystem, specializing in project site (objects) management, machine scheduling, and resource allocation.

## 📋 Features

- **Project Objects Management**: Comprehensive tracking of project-specific sites and clients.
- **Machine Planning**: Intelligent scheduling for vehicles and machinery.
- **Daily Activity Tracking**: Visual timelines for machine movements and project status.
- **Complex Matrix View**: High-level resource allocation across multiple projects and machines.

## 🛠 Configuration

Integrated via `module_config.php`.
- **Primary Entrance**: "Обекти" in the main navigation.
- **Visuals**: Leverages specialized JS libraries for timeline and matrix visualizations.

## 🚀 Installation

1. Ensure the `objects` folder is in `/modules/`.
2. The `ModuleManager` will initialize the dashboards and specialized planning views.
